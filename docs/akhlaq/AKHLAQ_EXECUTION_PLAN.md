# منظومة الأخلاق والآداب — تقرير المدير وخطّة التنفيذ

> المُخرَج النهائي لمرحلة البحث والمعمارية (A0). لا يبدأ التنفيذ حتى تُراجَع
> هذه الوثيقة وتُعتمَد. يُقرأ مع بقيّة `docs/akhlaq/`.

---

## 1. الرؤية

بناء **منظومة علمية وتربوية وعملية للأخلاق والآداب الإسلامية** داخل «طالب
العلم»، تنقل الطالب من *لا يعرف* إلى *صار حسن الخلق جزءًا من شخصيته*: معرفة
→ فهم → أدلّة → قدوة النبي ﷺ والصحابة → اكتشاف الخلل → تدريب → ممارسة →
محاسبة → مراجعة → ثبات.

**الاسم المقترح:** «الأخلاق والآداب» (يشمل حسن الخلق + الآداب + المنهج +
المكتبة + التدريب + الدفتر). يُثبَّت نهائيًّا في A3 بعد رؤية الواجهة.

**عنوان تعريفي ثابت:** *العلم يهديك، والخُلُق يزيّن علمك.*

**المعيار:** أن يقول الطالب «هذا المكان علّمني كيف أكون طالب علم» — لا «وجدت
أحاديث عن حسن الخلق».

## 2. البحث العلمي

في `HUSN_AL_KHULUQ_MASTER`: الخُلُق لغةً وشرعًا، الفرق بين الخَلْق والخُلُق،
منزلته، علاقاته (بالإيمان/العبادة/العلم/التزكية/الدعوة/طالب العلم)،
**التمييز السداسي** (خُلُق شرعي / أدب ثابت / أدب مستحبّ / خُلُق عامّ / عادة
وعُرف / اجتهاد وخلاف)، و**تمييز أنواع الأدلّة** (قرآن / مرفوع / أثر صحابي /
قول تابعي / قول عالِم / قصّة / حكمة يُنسب). كلّ متن يمرّ ببوّابة توثيق قبل
الظهور.

## 3. مصادر المعرفة

في `AKHLAQ_SOURCES`. الطبقات: القرآن عبر `quran.ai` (MCP) — لا من الذاكرة؛
السنّة بتحقّق يدوي مضبوط (لا MCP، فلا نشر حديث بلا تخريج ودرجة من مصدره)؛
آثار الصحابة/التابعين وأقوال العلماء من كتب الأدب/الزهد/الرقائق/السِّيَر/
تزكية النفس/أدب الطلب مع التمييز الصريح؛ المكتبة التراثية (Turath API)
كمصدر بحث وإحالة موسوم، لا نسخ كتب؛ كوربوس طالب العلم القائم كما هو. سجلّ
طبعات إلزامي. **قائمة تحقّق قبل اعتماد أيّ كتاب مصدرًا** في `SOURCES §6`.

## 4. الخريطة (Taxonomy)

في `AKHLAQ_TAXONOMY`. 11 مجالًا (القلب · اللسان · الغضب · التعامل · طالب
العلم · الأصناف · اليومية · الخلاف · الدعوة · التزكية · موسوعة النبي ﷺ)،
~120–160 عُقدة، حواف صريحة (`child_of` · `opposite_of` · `requires` ·
`strengthens` · `leads_to` · `prerequisite_for` · `related_to`)، وروابط
خارجية (`x_link`) إلى آيات/أحاديث/كتب/سيرة/دروس/محور مُحرّك الحياة. سلاسل
نموذجية تُعرَض للطالب.

## 5. المنهج (Curriculum)

في `AKHLAQ_CURRICULUM`. 13 مستوى (0 لماذا الأخلاق؟ → 12 التزكية والثبات)،
كلّ درس يمرّ بحلقة (تعلّم → افهم → شاهد → اختبر → طبّق → سجّل → راجع →
كرّر)، مسارات مرنة عبر «تركيز الأسبوع» بعد المستوى 1، تكامل اختياري مع
مُحرّك الحياة. المستوى لا يُقفَل قفلاً صارمًا (إرشاد لا منع).

## 6. نموذج البيانات

في `AKHLAQ_KNOWLEDGE_MODEL` + `AKHLAQ_DATA_SCHEMA`. الكيانات: `AkhlaqNode`
· `EvidenceItem` · `NodeCard` (تجميعة عرض) · `LessonUnit` · `Scenario`
(+options) · `PracticeTask` · `NotebookEntry` · `MoralProfile` · `SourceRef`.
جداول `akhlaq_*` محلّية (SQLite)، مبذورة من `assets/akhlaq/*.json.gz` عبر
`AkhlaqSync`؛ بيانات الطالب `akhlaq_*_user` لا تُبذَر. ترحيل v61→v65 على
دفعات. FTS للبحث. جاهزية مزامنة مستقبلية بلا كسر.

## 7. معمارية البحث

في `AKHLAQ_SEARCH`. محرّك محلّي (**ليس محادثة AI**): تطبيع عربي (إعادة
استخدام `normalizeArabicForSearch`) → فهم نيّة بالقواعد → كشف العُقدة عبر
جدول مرادفات + FTS → استعلام `akhlaq_fts` → ترتيب بالصلة/النوع/الدرجة →
بطاقات مجمّعة بالمصادر. قسم منفصل «من المكتبة (يتطلّب إنترنت)» عبر Turath.
تسامح أخطاء مطبعية. رسالة صادقة عند لا نتيجة.

## 8. معمارية الدفتر

في `AKHLAQ_NOTEBOOK`. 9 أنواع مدخلات + قوالب موجَّهة (محاسبة يوم/أسبوع،
خطّة إصلاح). يعيد استخدام محرّك التحشية والإرساء في Turath
(`saveResolvedAnchor`/`StudyAnnotation`) للاقتباس المربوط بموضع نصّ. ربط
بالمكتبة («أضِف إلى دفتر الأخلاق») + backlink («أين استخدمته؟») + قسم
«دفتري» في بطاقة العُقدة. تكامل اختياري مع مُحرّك الحياة. خصوصية صارمة
(محلّي، لا فهرسة).

## 9. معمارية الواجهة

- شاشة رئيسية جديدة **لا تشبه صفحة كتب**: بطاقة عنوان («الأخلاق والآداب» +
  العبارة التعريفية) → «ابدأ من البداية» / متابعة التقدّم (شريط %) → «أخلاق
  أدرسها» (رقائق) → مداخل: 📖 مكتبة الأخلاق · 🎓 المنهج · 🧠 مواقف أخلاقية ·
  📓 دفتر الأخلاق · 🔖 محفوظاتي · 🔍 البحث. **راقية لا مزدحمة** — تُصمَّم
  التجربة النهائية بعد فحص نظام التصميم القائم (`app_theme` + أنماط بطاقات
  الرئيسية/التراث)، لا نسخ المخطّط حرفيًّا.
- بطاقة العُقدة: أقسامها في `KNOWLEDGE_MODEL §1.3`؛ الأدلّة مفصولة بأقسامها
  وألوانها، **التصنيف السداسي ظاهر دائمًا**.
- الخريطة: تصفّح المجالات + عرض سلاسل العلاقات.
- مختبر المواقف: سيناريو → خيارات → «التصرّف وفق السنّة» + الدليل + سبب خطأ
  البقيّة + تأمّل. **لا نقاط ولا منافسة.**
- الملف الأخلاقي: أرقام نشاط تعلّم فقط.
- كلّ نصّ عبر `basicText()` ×13، RTL أوّلاً.

## 10. تدفّقات المستخدم (UX)

```text
أ) طالب جديد:
   الرئيسية → «ابدأ من البداية» → المستوى 0 → نيّة + اختيار تركيز أوّل →
   المستوى 1 (التمييز السداسي) → أوّل بطاقة عُقدة → أوّل تمرين يوم → أوّل
   مدخل دفتر.

ب) دراسة خُلُق:
   بطاقة العُقدة → التعريف/المنزلة/التصنيف → الأدلّة (مصنّفة) → علامات/ضدّ
   → «كيف أكتسبه» → موقف من المختبر → «طبّق اليوم» → «أضِف إلى دفتري».

ج) موقف واقعي:
   البحث «كيف أتعامل مع من أساء إليّ؟» → مواقف + عُقَد (العفو/كظم الغيظ) →
   قراءة الدليل → تسجيل «موقف أخطأت فيه» + «غدًا سأحاول».

د) محاسبة:
   الدفتر → «محاسبة اليوم» (قالب) → (اختياري) ربطها بملاحظة مُحرّك الحياة →
   نهاية الأسبوع: «محاسبة الأسبوع» + اختيار تركيز الأسبوع القادم.

هـ) من المكتبة:
   قراءة حديث في كتاب أدب (Turath) → «أضِف إلى دفتر الأخلاق» → يُحفَظ
   بالمصدر والموضع والعُقدة → لاحقًا: «أين استخدمته؟».
```

## 11. التكامل مع التطبيق القائم

| الطبقة | يُعاد استخدامه | يُبنى جديدًا |
|---|---|---|
| المعرفة | `KnowledgeGateway` + `KnowledgeProvider` + `SourceReference` + `KnowledgeFact` | `AkhlaqProvider` (domain `akhlaq`) + جداول `akhlaq_*` + `build_akhlaq_corpus.py` |
| المكتبة/القراءة | `TurathApiClient` + `TurathRepository` (بحث/صفحة/اقتباس) | قسم «من المكتبة» في بحث الأخلاق فقط |
| التحشية/الإرساء | `saveResolvedAnchor` + `StudyAnnotation` + `annotationsDigest` | طبقة عرض «دفتر الأخلاق» فوقها + جدول `akhlaq_notebook_user` |
| المراجعة المتباعدة | `knowledge_review_repository` | جدولة عُقَد/أدلّة الأخلاق |
| الموضوعات/الرسم | فكرة `quran_topic`/`knowledge_links`/`TopicIndexScreen` | `akhlaq_node`/`akhlaq_edge` محليًّا + شاشة «الخريطة» |
| البحث | `normalizeArabicForSearch` + نمط FTS (`quran_search_repository`) | `akhlaq_fts` + فهم النيّة + `akhlaq_synonym` |
| المستويات/الطبقات | نمط `TajweedTierScreen` + طبقة التعلّم | `akhlaq_level/lesson` + شاشة «رحلة الأدب» |
| العادة اليومية/المحاسبة | مُحرّك الحياة (محاور/مهامّ/دفتر يوم/ملخّص أسبوع) | محور «أخلاق» + تصدير `PracticeTask→life_task` |
| قاعدة البيانات | نمط الترحيل `_createVNTables` | ترحيلات v61→v65 |
| الترجمة | `basic_translations.dart` + `basicText()` | مفاتيح `akhlaq_*` ×13 |
| نظام التصميم | `app_theme` + أنماط بطاقات الرئيسية/التراث | شاشات المنظومة (تصميم جديد غير مزدحم) |
| عرض عرضي | شاشات الفقه/العقيدة/الحديث/السيرة/الآية | حقن بطاقة «أخلاق مرتبطة» عبر `x_link` |

**قاعدة:** لا يُعاد بناء موجود إلا إذا خدم الهدف بوضوح. الجديد محصور في
الجدول أعلاه.

## 12. مراحل التنفيذ

في `AKHLAQ_ROADMAP`: A0 (هذه) → A1 هيكل تقني فارغ → A2 أوّل دفعة معرفة
موثّقة → A3 الرئيسية + بطاقة العُقدة + الخريطة → A4 المنهج 0–3 → A5 مختبر
المواقف → A6 الدفتر → A7 البحث → A8 الملف الأخلاقي + ربط مُحرّك الحياة →
A9 موسوعة النبي ﷺ → A10 التوسيع والصقل. كلّ مرحلة تُغلَق باختبارات +
analyze + تحقّق جهاز + تحديث تقرير التغطية.

## 14. الجودة (QA)

في `AKHLAQ_QA`: بوّابات التوثيق / التصنيف / سلامة الخريطة / المنهج / البحث
/ الواجهة، + تقرير `AKHLAQ_COVERAGE.md`، + **مراجعة بشرية موسومة إلزامية
قبل نشر أيّ دفعة معرفة**.

## 15. المخاطر

في `AKHLAQ_ROADMAP` (المخاطر عالية الأولوية): (1) خطأ التوثيق — بوّابة بناء
تُفشِل + مراجعة بشرية؛ (2) الخلط خُلُق/أدب/عادة — `content_class` إلزامي
وظاهر؛ (3) تضخّم النطاق — دفعات صغيرة، نشر الموثّق فقط؛ (4) الانزلاق لتقييم
الطالب — منع صريح + `MoralProfile` أرقام فقط؛ (5) الاعتماد على Turath
أونلاين — المنظومة تعمل بلا إنترنت؛ (6) الترخيص — لا نسخ كتب كاملة.

## 16. ما يجب عدم فعله

- ❌ اختصار المشروع إلى `AkhlaqScreen`.
- ❌ صفحة قائمة نصائح ثابتة بلا أدلّة/تصنيف/تخريج (هذا `adab_screen` الحالي).
- ❌ نسبة متن للنبي ﷺ/الصحابة بلا تخريج.
- ❌ إعطاء درجة لحديث اجتهادًا.
- ❌ خلط مرفوع/أثر/قول عالم في بطاقة واحدة بلا فصل ووسم.
- ❌ تحويل عادة/عُرف إلى «سنّة».
- ❌ إخفاء `content_class` عن الطالب.
- ❌ تقييم شخصية الطالب أو تشخيصه.
- ❌ محادثة AI حيّة تواجه الطالب.
- ❌ نسخ كتب كاملة من `turath.io`.
- ❌ إعادة بناء محرّك تحشية/مصادر/بحث جديد بدل الموجود.
- ❌ البدء بالتنفيذ قبل اعتماد هذه المعمارية.
