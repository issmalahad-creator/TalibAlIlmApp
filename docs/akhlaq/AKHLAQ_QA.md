# منظومة الأخلاق والآداب — الجودة والتحقّق (QA)

> بوّابات لا تُتجاوَز. المنظومة تتعامل مع نصوص شرعية؛ خطأ التوثيق أخطر من
> خطأ الكود.

---

## 1. بوّابة التوثيق (لكلّ `EvidenceItem` قبل `published`)

```text
[ ] evidence_type محدَّد.
[ ] content_class محدَّد ومتّسق معه (SOURCES §2.2).
[ ] source_title + source_edition_id موجودان في سجلّ الطبعات.
[ ] locator موجود (رقم حديث / مج+ص / سورة:آية).
[ ] مرفوع؟ → grading ∈ المجموعة المضبوطة، و grading_authority، و takhrij — كلّها غير فارغة.
[ ] آية؟ → جُلبت عبر quran.ai، وطوبقت بالكوربوس المحلّي (المحلّي يفوز عند الاختلاف).
[ ] حكمة غير ثابتة؟ → مصاغة «يُنسب…/اشتهر بلا إسناد»، لا كحديث.
[ ] reviewed_by موسوم.
[ ] لا خلط في نفس الحقل بين مرفوع وأثر وقول عالم.
```
أداة البناء `tool/build_akhlaq_corpus.py` **تُفشِل** إن اختلّ أيّ بند.

## 2. بوّابة التصنيف

```text
[ ] كلّ عُقدة/دليل له content_class ظاهر للطالب في الواجهة.
[ ] لا مادة aadah_urf/ijtihad_khilaf منسوبة إلى «سنّة» أو «قال ﷺ».
[ ] khuluq_shari مستند إلى دليل quran/hadith_marfu صحيح واحد على الأقلّ.
[ ] حديث daif/daif_jiddan/mawdu لا يظهر كدليل (يجوز في «أخطاء شائعة» موسومًا بمصدر الحكم).
```

## 3. بوّابة سلامة الخريطة (`AKHLAQ_TAXONOMY §6`)

```text
[ ] لا عُقدة khuluq/adab/vice/daily/relation_ctx/prophetic بلا child_of مجال.
[ ] لا حافة إلى عُقدة غير منشورة.
[ ] requires/prerequisite_for بلا حلقات (DAG).
[ ] كلّ vice لها opposite_of واحدة.
[ ] كلّ عُقدة منشورة لها summary_ar + level_hint + دليل منشور واحد (إلا domain).
[ ] كلّ x_link يشير إلى هدف صالح (آية موجودة / كتاب معروف / درس موجود).
```

## 4. بوّابة المنهج (`AKHLAQ_CURRICULUM §5`)

```text
[ ] لكلّ مستوى منشور: intro_ar + outcome_ar + ≥ 3 دروس منشورة.
[ ] كلّ درس يشير إلى عُقدة منشورة واحدة على الأقلّ.
[ ] كلّ عُقدة يشير إليها درسٌ لها دليل منشور.
```

## 5. بوّابة البحث (`AKHLAQ_SEARCH §7`)

```text
[ ] ~20 استعلامًا مرجعيًّا، النتيجة الأولى المتوقَّعة ثابتة.
[ ] لا draft في أيّ نتيجة.
[ ] التطبيع يطابق صيغ الحركات/الهمزات.
[ ] استعلام بلا نتيجة → رسالة صادقة لا صفحة فارغة.
```

## 6. بوّابة الواجهة/التجربة (قبل «تمّ» لأيّ شاشة)

```text
[ ] كلّ نصّ عبر basicText() ×13 لغة (لا عربي ثابت).
[ ] RTL سليم، لا overflow.
[ ] بطاقة العُقدة: الأدلّة مفصولة بأقسامها وألوانها، التصنيف ظاهر.
[ ] «دفتري» داخل البطاقة يعمل، والـbacklink «أين استخدمته؟» يعمل.
[ ] مختبر المواقف لا يعطي «درجة/نقاط»؛ يعطي مقارنة بالسنّة + دليلًا + تأمّلًا.
[ ] الملف الأخلاقي أرقام نشاط فقط، لا سِمات شخصية.
[ ] تحقّق على المحاكي ثمّ على جهاز إسماعيل (قاعدة التطبيق القائمة).
```

## 7. مؤشّرات الاكتمال (تقرير `docs/akhlaq/reports/AKHLAQ_COVERAGE.md`)

يولّده اختبار يمرّ على كلّ الأصول:
```text
- عدد العُقَد المنشورة / المستهدَفة (~120–160)
- نسبة العُقَد التي لها ≥ 1 دليل منشور
- توزيع evidence_type (كم quran / marfu / athar / qawl / qissa)
- كم مرفوع بلا grading (يجب = 0 في المنشور)
- كم content_class = khuluq_shari بلا دليل quran/marfu (يجب = 0)
- المستويات المكتملة / 13
- عدد المواقف والتمارين المنشورة
- عُقَد يتيمة في الخريطة (يجب = 0)
- روابط x_link مكسورة (يجب = 0)
```

## 8. قائمة الاختبارات

- `test/akhlaq_corpus_qa_test.dart` — يبذر الأصول، يفحص بوّابات 1–4، يكتب
  تقرير التغطية، يُفشِل عند أيّ خرق.
- `test/akhlaq_search_test.dart` — الاستعلامات المرجعية + التطبيع + لا draft.
- `test/akhlaq_taxonomy_test.dart` — DAG على requires/prerequisite_for،
  لا حواف يتيمة، كلّ vice لها ضدّ.
- `test/akhlaq_repository_test.dart` — بطاقة العُقدة تُركَّب صحيحًا،
  الدفتر يدور، backlink «أين استخدمته؟» يرجع المدخلات الصحيحة، الملف
  الأخلاقي أرقام لا سِمات.
- (widget) شاشة رئيسية + بطاقة عُقدة تُرسَم RTL بلا overflow (بحذر من
  عوائق fake-async كما في `corpus_panels`).

  ما نُسب للنبي ﷺ أو الصحابة له تخريج.
- هذه ليست خطوة كود؛ هي شرط إطلاق.
