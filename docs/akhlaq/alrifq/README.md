# docs/akhlaq/alrifq/ — الشريحة الرأسية المرجعية: «الرفق»

**الحالة:** مواصفة محتوى **منجَزة** — بحثٌ + ترجمةٌ حرفيّة + تحقّقٌ آليٌّ
أخضر. **جاهزة للانتقال إلى التنفيذ البرمجيّ (P3).**

**سياسة الاعتماد:** `Source‑grounded automated validation` هو الخطّ
الأساسيّ (`tool/akhlaq_validate.py`). المراجعة البشرية **طبقةٌ اختياريّة
لاحقة**، لا تُوقِف التنفيذ؛ الـmetadata محفوظةٌ للتتبّع.

**الغرض:** أن تكون «الرفق» **القالب المرجعي** لكل فضيلةٍ بعدها (الصدق،
التواضع، كظم الغيظ، حفظ اللسان، قبول الحقّ، أدب الخلاف).
