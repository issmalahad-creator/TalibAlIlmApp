# docs/akhlaq/alrifq/ — الشريحة الرأسية المرجعية: «الرفق»

**الحالة:** مرحلة CONTENT RESEARCH منجَزة — **مواصفة محتوى قابلة للمراجعة
البشرية**. **لا كود، لا SQLite، لا migration، لا UI، لا بيانات وهمية.**

**الغرض:** أن تكون «الرفق» **القالب المرجعي** لكل فضيلةٍ بعدها (الصدق،
التواضع، كظم الغيظ، حفظ اللسان، قبول الحقّ، أدب الخلاف). لا يُنسَخ القالب
حتى تُعتمَد هذه الوحدة بعد المراجعة البشرية.

## ترتيب القراءة

1. `AR-RIFQ_SOURCE_RESEARCH.md` — معنى الرفق، علاقاته، منهج البحث،
   الاستعلامات المنفَّذة فعليًّا على Turath، حدود البحث.
2. `AR-RIFQ_EVIDENCE.md` — 11 دليلًا مرشّحًا + 3 مؤجَّلة. كلٌّ بحقوله
   الكاملة، مع فصلٍ صريح `[EVIDENCE]` عن `[PEDAGOGICAL INTERPRETATION]`.
3. `AR-RIFQ_BEHAVIOR_MAP.md` — 12 مهارة فرعية، لكلٍّ سلسلة كاملة
   (مؤشّر → موقف ملحوظ → صفات الاستجابة الصحيحة → الخطأ الشائع → سؤال
   مراجعة → دليل) + جدول تتبّع + التوتّرات الخمسة.
4. `AR-RIFQ_SCENARIOS.md` — 12 سيناريو، خياراتها موسومة بأبعاد الاستجابة
   + verdict + why + دليل، بصعوبات 1–8، 3 منها مركّبة لا تكشف موضوعها.
5. `AR-RIFQ_CURRICULUM.md` — 7 مراحل + جدول التكرار المتباعد
   D1/D2/D4/D7/D14/D30/D60.
6. `AR-RIFQ_REVIEW.md` — 43 نقطة مراجعة بشرية مصنّفة (توثيق / تعريف /
   توتّرات / مهارات / سيناريوهات / منهج / بنود تربوية / قرارات).
7. `AR-RIFQ_CONTENT_SPEC.md` — المواصفة المجمَّعة + **الأرقام النهائية
   الثمانية**.

`_raw/*.json` — نتائج واجهة Turath الخام (أثر تدقيق).

## بند القبول

«الرفق» **غير مكتملة** حتى نستطيع تتبّع **كل سلوكٍ تدريبيّ** إلى دليلٍ أو
نوسمه صراحةً `[TARBAWI]`، وحتى تمرّ كل مادّةٍ بالمراجعة البشرية الموسومة.
