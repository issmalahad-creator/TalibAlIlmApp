# منظومة الأخلاق والآداب — الخريطة (Taxonomy / Knowledge Graph)

> ليست قائمة مسطّحة. هي **شجرة مجالات** + **رسم علاقات** بين العُقَد.
> يبني عليها: التنقّل، البحث، «رحلة الأدب»، وربط العُقَد ببعضها وبباقي
> التطبيق.

يُشتقّ التنفيذ منها في `AKHLAQ_DATA_SCHEMA` (جداول `akhlaq_node`،
`akhlaq_edge`). تصميم `knowledge_links` القائم في `docs/SUPABASE_ARCHITECTURE`
هو النموذج المرجعي لشكل الحواف؛ نبدأ محليًّا (SQLite) والمزامنة لاحقًا.

---

## 1. أنواع العُقَد (`node_kind`)

| النوع | الوصف | مثال |
|---|---|---|
| `domain` | مجال جامع (فرع الشجرة) | «أخلاق اللسان» |
| `khuluq` | صفة نفسية (خُلُق) | «الصدق» |
| `adab` | هيئة سلوك (أدب) | «أدب الاستماع» |
| `vice` | ضدّ/آفة تُدرَس للتحذير | «الغيبة» |
| `daily` | أدب حياة يومية | «أدب الطعام» |
| `relation_ctx` | أدب مع صنف من الناس | «الآداب مع الجار» |
| `prophetic` | باب من موسوعة أخلاقه ﷺ | «رحمته ﷺ بالأطفال» |

كل عُقدة تحمل: `slug` · `title_ar` · `node_kind` · `domain_id` ·
`content_class` (يورَث ويُراجَع) · `summary_ar` (سطر واحد) · `sort` ·
`level_hint` (المستوى المقترح في المنهج) · `status`.

## 3. أنواع الحواف (`edge_type`) بين العُقَد

| النوع | المعنى | مثال |
|---|---|---|
| `child_of` | تبعيّة شجرية | «الصدق» child_of «أخلاق اللسان» |
| `opposite_of` | ضدّ | «الغيبة» opposite_of «حفظ اللسان» |
| `requires` | لا يقوم إلا به | «كظم الغيظ» requires «الحِلْم» |
| `strengthens` | يقوّيه/يعين عليه | «الصبر» strengthens «الحِلْم» |
| `leads_to` | نتيجته | «كظم الغيظ» leads_to «العفو» |
| `prerequisite_for` | مقدّمة له في المنهج | «مراقبة الله» prerequisite_for «الإخلاص» |
| `related_to` | صلة عامّة | «التواضع» related_to «أدب السؤال» |
| `evidence_shared` | يشتركان في دليل واحد | يُولَّد آليًّا عند الإدخال |

كل حافة: `from_node` · `edge_type` · `to_node` · `note_ar?` ·
`source_ref?` (إن كانت العلاقة نفسها منقولة عن عالِم).

## 4. سلاسل نموذجية (تُعرَض للطالب في «الخريطة»)

```text
الغضب  ──requires──►  الحِلْم  ──strengthened_by──  الصبر
                         │
                    leads_to
                         ▼
                       العفو  ──leads_to──►  سلامة الصدر
```

```text
مراقبة الله ──prerequisite_for──► الإخلاص ──opposite_of──► الرياء
      │                                │
 strengthens                      strengthens
      ▼                                ▼
 محاسبة النفس ◄──related_to──► التواضع
```

```text
أدب السؤال ──requires──► التواضع للعلم ──opposite_of──► التعالُم
     │
 related_to
     ▼
 أدب الاستماع ──strengthens──► أدب المناظرة ──requires──► الإنصاف
```

## 5. تكامل الخريطة مع باقي التطبيق (روابط خارجية)

نوع حافة إضافي `x_link` يربط عُقدة أخلاق بكيان خارج المنظومة:

| الهدف | المعنى | مصدر البيانات |
|---|---|---|
| `ayah:(surah,ayah)` | آية تؤصّل العُقدة | كوربوس القرآن + `quran_topic` |
| `hadith_item:id` | حديث في المنظومة نفسها | `akhlaq_evidence` |
| `turath:(book,page)` | موضع في كتاب بالمكتبة | Turath API |
| `sira_event:id` | موقف من السيرة | قسم السيرة (عند بنائه) |
| `lesson:id` | درس فقه/عقيدة مرتبط | طبقة التعلّم |
| `life_pillar:akhlaq` | محور «أخلاق» في مُحرّك الحياة | `life_pillars` |

هذه الروابط تُنتج في واجهات أخرى بطاقات: «أخلاق مرتبطة بهذا الموضوع» /
«مواقف أخلاقية من السيرة» / «الأخلاق المستفادة من الحديث».

---

## 6. قواعد سلامة الخريطة (تُفحَص في `AKHLAQ_QA`)

- لا عُقدة `khuluq`/`adab`/`vice` بلا `child_of` مجال.
- لا عُقدة منشورة بلا `summary_ar` و`level_hint`.
- كل `vice` لها `opposite_of` واحدة على الأقلّ.
- لا حافة إلى عُقدة غير موجودة/غير منشورة.
- `requires`/`prerequisite_for` لا تُنشئ حلقة (DAG على هذين النوعين).
- كل عُقدة منشورة لها `EvidenceItem` واحد منشور على الأقلّ (إلا `domain`).
